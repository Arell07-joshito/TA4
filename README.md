# The Coca-Cola Company (1886–2026) · Icono Global

Sitio web estático responsivo basado en la historia, modelo de negocio, finanzas, cultura pop y sostenibilidad de **The Coca-Cola Company**.

## Estructura del proyecto

```text
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── README.md
```

## Cómo publicarlo en GitHub Pages

1. Crea un nuevo repositorio en GitHub.
2. Sube todos los archivos de esta carpeta a la rama `main`.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/ (root)`, y guarda los cambios.
